# Руководство пользователя FOCAL/RARS

Нормативный продукт проекта — `rars_focal_interpreter.asm`, работающий внутри
RARS 1.6 в режиме RV32. Python-реализация остаётся вспомогательным прототипом и
инструментом разработки, но не является oracle поведения FOCAL.

## Запуск и REPL

Откройте ASM в RARS, выполните Assemble и Run. После приглашения можно вводить
immediate-операторы либо сохранять нумерованные строки:

```text
FOCAL/RARS REPL. Enter HELP for commands.
> SET A=5
> TYPE A*2,!
10.0
> 1.10 TYPE "stored",!
> 1.20 QUIT
> LIST
1.10 TYPE "stored",!
1.20 QUIT
> RUN
stored
```

Нормативный номер имеет вид `group.line`: группы 1–99, строки 01–99, `.00`
запрещён. Один знак после точки означает десятки, поэтому `2.1` = `2.10`, но
`2.01` — другая строка. LIST/WRITE/SAVE выводят каноническую форму `g.ll`.
Повторный ввод номера заменяет строку, а номер без текста удаляет её.

Команды среды: `RUN`, `LIST`, `LOAD file`, `SAVE file`, `ERASE`, `HELP`,
`EXIT`. `QUIT/Q` — оператор FOCAL: он прекращает только текущее выполнение и
возвращает REPL. Для завершения процесса используется `EXIT`. `G`, `GO` и
`GOTO` — операторы FOCAL; без цели они передают управление первой stored line.

## Операторы обязательного профиля

- `SET/S variable=expression` — присваивание; значимы первые два символа имени.
- `TYPE/T item,...` — строки, выражения, `!`; форматы `%`, `%W`, `%W.0d`.
- `ASK/A item,...` — подсказки, `!` и ввод выражений в scalar/indexed target.
- `GOTO/G/GO [g.ll]` — переход по таблице compiled line offsets.
- `IF/I (expr) neg[,zero[,pos]]` — ветвление по знаку Float32; отсутствующая
  ветвь означает fall-through, оба signed zero выбирают zero branch.
- `FOR/F var=start[,step],limit; body` — тело до конца физической строки,
  inclusive limit, шаг любого ненулевого конечного знака.
- `DO/D g.ll` вызывает строку, `DO/D g` — группу; `RETURN/R` возвращает раньше,
  естественный конец строки/группы возвращает автоматически.
- `WRITE/W [ALL|g|g.ll]` — весь source, группа или строка.
- `COMMENT/C` игнорирует остаток физической строки.
- `QUIT/Q` завершает текущее FOCAL execution.

Полные имена и перечисленные сокращения проверяются как целые токены. Регистр
ключевых слов и идентификаторов несущественен, но текст строковых литералов и
operator text в storage сохраняется.

## Выражения и данные

Поддержаны fixed/exponent decimal literals (`.45`, `-.02`, `1.77E2`), операции
`+ - * / ^`, унарный знак и круглые, квадратные, угловые скобки. Приоритет:
`^`, затем `*`, затем `/`, затем `+`/`-`; одинаковый приоритет — слева направо.
Показатель `^` должен быть целым; `0^0=1`, `0` в отрицательной степени — ошибка.

Имена начинаются с латинской буквы, содержат буквы/цифры; имена на `F`
зарезервированы. Одномерные indexed variables создаются без DIM, индекс
округляется round-to-nearest-even. Общий максимум scalar/indexed entries — 512.
Неопределённое значение читается как `0.0`. Функции: `FABS`, `FSQT`, `FITR`,
`FSGN`. Числовая модель — IEEE-754 Float32.

## Файлы и вместимость

`LOAD` потоково читает LF/CRLF-файл и атомарно заменяет storage только после
полной проверки номеров, длины и числа строк. Ошибка оставляет старую программу.
`SAVE` потоково пишет sorted canonical source с LF; case, spaces, сокращения,
`;` и comments в operator text не переписываются.

Хранилище вмещает 128 активных строк по 127 байт operator text плюс NUL. RUN
компилирует эти slots напрямую без общего лимита stored source в 8191 байт.
Отдельные границы: wordcode 16384 байта, VM stack 512 Float32, symbol table 512,
DO stack 16 и FOR stack 16; превышение завершается контролируемой диагностикой.

## Ограничения профиля

Не входят: двумерные массивы, DO ALL, вычисляемые цели GOTO/DO, расширенная
историческая область FOR, вещественная степень, ASK `%`/`¤`, буквенные ответы,
полная историческая TYPE-система, FSIN/FCOS/FEXP/FLOG/FRAN, графика и периферия.
Старые `IF ... THEN` и `FOR ... DO` могут существовать только как изолированный
legacy compatibility path и не являются нормативной грамматикой.

## Автоматическая проверка

После задания `RARS_JAR` итоговая нормативная приёмка запускается из корня:

```powershell
py -3 -B tools/run_rars_profile_tests.py
```

Она выполняет настоящий RARS. Python в этом запуске только готовит fixtures,
передаёт stdin и сравнивает заранее заданные exact stdout/bytes.
